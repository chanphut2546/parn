สเปก LINE Chatbot (สรุปจากเล่มปริญญานิพนธ์ BSIT68T3-15 บทที่ 3.10, 5.3, 5.6 และภาคผนวก ก)
==========================================================================================

หมายเหตุ: ในเล่มไม่ได้ตีพิมพ์โค้ดสร้างการ์ดข้อความ (Flex Message) รูปภาพ Rich Menu และตัวจัดการ
Postback ฉบับเต็ม ชุดนี้จึงมีโค้ดที่ "เขียนเพิ่ม" ตามสเปกด้านล่างไว้ใน App_Server/app.py
(ส่วนที่มีป้ายกำกับ [เขียนเพิ่ม]) หน้าตาจริงของการ์ดอาจต่างจากของจริงที่ใช้งานอยู่
ส่วนรูปภาพ Rich Menu ไม่มีในชุดนี้ (ดูหน้าตาเมนูในรูปผนวกที่ ก.1 ของเล่ม)

1) Rich Menu (4 ปุ่ม)  -- ต้องสร้างใน LINE Official Account Manager / Messaging API เอง
   - "รดน้ำ"       -> Postback data = act=water   : แสดงการ์ดให้เลือกโซน แล้วรดน้ำครั้งละ 10 นาที
   - "หยุดน้ำ"      -> Postback data = act=off_all : สั่งหยุดปั๊ม (รีเลย์ช่อง 3 กดแทนปุ่ม STOP)
   - "วัดอุณหภูมิ"   -> Postback data = act=temp    : แสดงอุณหภูมิ ความชื้นล่าสุด สถานะปั๊ม (และเวลาที่เหลือ)
   - "เพิ่มเติม"     -> Postback data = act=more    : เมนูเพิ่มเติม มีปุ่ม "ดูกราฟข้อมูลทั้งหมด"
                                                     (เปิดหน้า /graph ย้อนหลัง 24 ชั่วโมง หรือ 7 วัน)
   ปุ่มบนการ์ดเลือกโซนส่ง  act=water&ch=<ช่องรีเลย์>  (ค่าเริ่มต้นโซน 1-3)
   นอกจากนี้ app.py ที่เขียนเพิ่มรับข้อความพิมพ์ "รดน้ำ" "หยุดน้ำ" "วัดอุณหภูมิ" "เพิ่มเติม" ได้ด้วย

2) การแจ้งเตือนที่ Chatbot ส่งหาผู้ใช้ (push หาผู้ใช้ที่สั่งงานล่าสุด)
   - รดน้ำเสร็จแล้ว (ครบเวลา)               -> done_card
   - อุปกรณ์ ESP32 ขาดการเชื่อมต่อ > 120 วินาที -> offline_card
   - อุปกรณ์กลับมาเชื่อมต่อแล้ว               -> back_online_card
   - สั่งรดน้ำไม่ได้เพราะ ESP32 ออฟไลน์         -> cannot_open_card
   - ยืนยันการเปิดรดน้ำ                       -> confirm_on_card
   - หยุดน้ำแล้ว                             -> stopped_card

3) การเชื่อมต่อ
   - LINE Platform เรียก Webhook ที่ POST /callback (ตรวจลายเซ็น X-Line-Signature)
   - เปิดช่องทางสาธารณะด้วย ngrok (โดเมนคงที่) -> http://localhost:5000 บน Raspberry Pi
   - ตั้งค่า Webhook URL ใน LINE Developers Console เป็น https://<โดเมน ngrok>/callback
   - ตั้ง PUBLIC_BASE_URL และ GRAPH_TOKEN ใน .env เพื่อให้ปุ่ม "ดูกราฟข้อมูลทั้งหมด" ทำงาน

4) ความปลอดภัย
   - ใครก็ตามที่เพิ่มบอทเป็นเพื่อนจะสั่งปั๊มได้ ถ้าไม่ตั้ง ALLOWED_USER_IDS ใน .env
     แนะนำให้ใส่ LINE userId ของผู้ดูแลสวนเท่านั้น

5) สิ่งที่ต้องเตรียมเพิ่มเอง
   - รูปภาพ Rich Menu และการสร้าง Rich Menu ผูกกับ LINE Official Account
   - ค่า Channel Access Token / Channel Secret ของ LINE Official Account
